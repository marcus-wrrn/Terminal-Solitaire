# Solitaire

A terminal-based solitaire (Klondike) game built with Rust and [ratatui](https://ratatui.rs/).

## Installation

```bash
cargo install solitaire
```

## Usage

Simply run:
```bash
solitaire
```

## Features

- Full Klondike solitaire gameplay
- Keyboard and mouse controls
- Terminal-based UI with smooth rendering
- Win animations and auto-play
- Options menu with rebindable keys

## Controls

- Mouse: Click to select and move cards
- Keyboard: Navigate with arrow keys, select with Enter/Space
- Press `?` or `h` for help menu
- Press `Esc` to open options menu

## Requirements

- A terminal emulator with color support
- Rust 1.70+ (if building from source)
